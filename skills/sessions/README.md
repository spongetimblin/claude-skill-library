# sessions

Merged into [search](../search/) on 2026-10-28. `/search 🏥` lists your sessions on a topic, `/search 🏥 dentist` searches within one, and `/search --topics` counts them. The script is now `search/scripts/sessions.py`, and the topic keys and the fallback rule go in search's `config.json`, as its README describes. This folder stays only so that older links to it still land somewhere.
